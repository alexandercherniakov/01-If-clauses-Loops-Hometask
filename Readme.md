# Задание 01. Блоки ветвления, циклы

Задания выполняются по порядку.  
Желательно использовать те возможности языка, которые были пройдены.  
Каждое задание должно быть оформлено в отдельный файл `taskN.py`.  
Задания со \* не обязательны для выполнения.

---

## Задача 1. Количество грибов

Пользователь вводит целое число — количество собранных грибов.
Программа должна вывести сообщение вида:

- "Мы собрали **1 гриб**"
- "Мы собрали **2 гриба**"
- "Мы собрали **5 грибов**"
  То есть необходимо подобрать правильную форму слова **"гриб"** в зависимости от числа.
  Если введено отрицательное число — вывести `"Input error"`.

## Задача 2. Скидка по накоплениям и сумме текущей покупки

Пользователь вводит:

- общую сумму **накопленных покупок** (число ≥ 0)
- сумму **текущей покупки** (число ≥ 0)

На основе накоплений определяется базовый уровень скидки:

- если накопления < 500 → скидка **0%**
- если 500–999 → скидка **5%**
- если 1000–4999 → скидка **10%**
- если ≥ 5000 → скидка **15%**

Дополнительная скидка:

- если текущая покупка > 300 → добавить ещё **5%**
- если текущая покупка > 1000 → добавить **10%** (вместо 5%)
- максимальная итоговая скидка — **25%**

Если введены отрицательные числа — вывести `"Input error"`.

Программа должна вывести:

- итоговую скидку
- сумму к оплате после применения скидки

### Пример

Ввод:  
Накопления: 1200  
Текущая покупка: 450

Вывод:  
Итоговая скидка: **15%**  
К оплате: **382.5**

## Задача 3. Итоговая буквенная оценка

Пользователь вводит **5 целых чисел** — результаты пяти тестов (каждое от 0 до 100). Если хотя бы одно значение вне диапазона 0–100, программа выводит `"Input error"` и завершает работу.

Если все оценки корректны:

1. вычислить **среднее арифметическое** пяти чисел
2. определить итоговую буквенную оценку по шкале:

- < 60 → **F**
- 60–79 → **D**
- 80–89 → **C**
- 90–94 → **B**
- 95–100 → **A**

Вывести **только итоговую буквенную оценку**.

## Задача 4\*. Размен суммы N рублей

Пользователь вводит целое число **N** (N ≥ 1) — сумму в рублях.
Необходимо вывести **все возможные варианты размена** этой суммы монетами номиналом:

- 5 рублей
- 2 рубля
- 1 рубль

Каждый вариант должен быть представлен в виде количества монет каждого типа:
5-рублёвых: a, 2-рублёвых: b, 1-рублёвых: c
где **a**, **b**, **c** — неотрицательные целые числа

### Пример

Ввод:  
N = 6
Возможные варианты размена:

- 5-рублёвых: 1, 2-рублёвых: 0, 1-рублёвых: 1
- 5-рублёвых: 0, 2-рублёвых: 3, 1-рублёвых: 0
- 5-рублёвых: 0, 2-рублёвых: 2, 1-рублёвых: 2
- 5-рублёвых: 0, 2-рублёвых: 1, 1-рублёвых: 4
- 5-рублёвых: 0, 2-рублёвых: 0, 1-рублёвых: 6
